# MatrixPro - Linear Algebra & Mathematical Modeling Platform

MatrixPro is a professional educational tool designed for students and mathematicians. It provides an advanced interface for performing matrix operations with detailed, audience-specific explanations.

## 🚀 Features

- **Multi-language Support**: Full support for Uzbek, English, and Russian.
- **Dual Learning Modes**: 
  - **Elementary**: Simplified explanations for school students.
  - **Higher Math**: Academic-level analytical traces for university students.
- **Detailed Traces**: Step-by-step arithmetic for addition, multiplication, determinant, inverse, rank, and systems of equations.
- **Interactive Analytics**: Real-time operation statistics visualized with Chart.js.
- **Premium Design**: Modern glassmorphism UI with dark and light mode support.
- **Operation History**: Track and review your last calculations.

## 🛠 Technology Stack

- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+)
- [Math.js](https://mathjs.org/) for linear algebra computations.
- [MathJax](https://www.mathjax.org/) for LaTeX rendering.
- [Chart.js](https://www.chartjs.org/) for data visualization.

## 📦 Getting Started

Simply open `index.html` in any modern web browser. No installation or complex setup required.
